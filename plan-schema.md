# Planning Schema for Projects

This document is the template for the categories all projects should contain.

1. Overview - Description with numbered high-level list of major todos
2. Overhead - Tasks (and their associated costs) involved in planning and preparing (e.g. survey data)
3. Todo - Master numbered list of overall steps
4. Components - List of items to purchase and their costs per Todo item number
5. Schedule - When the project will take place, estimate of how long, and calendar of steps aligned with dates and times
6. Procedures - Flow chart of items from Todo list and components list detailing how and when they will be executed
7. Cost - Rough Estimate, Itemized Overall cost calculation of the project
8. Cost Benefit - Cost benefit analysis for: added value / cost and added value / time
9. Considerations - Topics to consider when executing project (e.g. where will we shower if the bathroom is out for 3 days?)
